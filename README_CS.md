# Introduction

This lab repository for *Introduction To Ada* has been loaded here into Google Cloud Shell, a Debian-based virtual container.
Warning: this is an ephemeral virtual computer and any work you do will be erased when the Google Cloud Shell ends.
Google sets the maximum idle time to 40 minutes, and the maximum elapsed time to twelve hours.

Follow these steps:

1. Close the *cloudshell* terminal window at the bottom of the browser window.
1. Wait for all the steps in the spin-up dialog to finish, and wait for the development UI to appear.
1. Close the panel to the left of these instructions.
    Gemini Code Assist has been deprecated and no longer available from Google,
    but the panel still opens to try and provide AI chat.
1. From the Visual Studio Code menu at the top left of the browser window (not the browser menu), click on <i>Terminal &rarr; New Terminal</i>.
1. In the new terminal window run the command <code>scripts/gcs_setup.sh</code> and wait for it to complete.
1. In the <i>Explorer</i> panel at the left right-click the <i>README.md</i> file and select <code>Open Preview</code>.
1. Close this window when these tasks are complete.
